# Netanel Aknin

Backend and integration engineer based in Israel. I work mainly in C#/.NET and SQL Server, with TypeScript, Node.js and React on the full-stack side.

Most of my work is connecting systems that were never designed to talk to each other: industrial controllers over Modbus, SAP and Amdocs behind a telecom's eSIM platform, a Kafka telemetry pipeline for IoT monitoring, and today Microsoft Dynamics 365 Business Central and shipping carriers on a warehouse management platform.

## What I do at work

- ERP and WMS integration: AL extensions for Business Central, webhooks, delta sync, XSLT mapping pipelines
- .NET services: API gateways (YARP), backend-for-frontend services, extensibility APIs
- Security work in the data layer: SQL injection hardening, role-based access
- Test and delivery: Cypress, NUnit, Azure DevOps pipelines

The code for that lives in private repositories. What is public here is what I build on my own time.
